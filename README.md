# Noolagam – Library Management App

## Project Description
Noolagam is a web-based Library Management App prototype designed to help users browse books, search for books, check availability, and demonstrate book issuing and returning.

## Objectives
- Provide a simple interface for browsing books.
- Allow users to search and filter books.
- Demonstrate book issuing and returning.
- Track book availability and due dates.
- Provide basic book management features.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Storage

## Main Features
- User registration and login
- Book search and filtering
- Book details and availability
- Issue and return books
- Saved books
- Basic administrator controls
- Test cases and validation
